# EPROM display decoder — editable schematic

[EPROM_Circuit.kicad_sch](EPROM_Circuit.kicad_sch) is the locally retained KiCad schematic for the EPROM/display circuit, copied without modifications. The [portfolio case study](https://m-lutter.github.io/portfolio/projects/eprom-display.html) describes Maxwell Lutter's decoder design, truth-table work, and physical assembly.

This is editable circuit-design source. The programmed lookup-table figures and original circuit notes remain linked from the case study; a separate EPROM binary or programming script was not found. Open the schematic in KiCad to inspect its components and connections. No new schematic validation or hardware test is claimed by this archive addition.
